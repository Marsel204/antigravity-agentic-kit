# /plan — Implementation Planning Phase

When invoked, the agent MUST:
1. Break down the task into discrete, independent milestones (1–3 files per milestone).
2. Define clear pass/fail acceptance criteria for each milestone.
3. Define the rollback procedure.
4. Stop and request explicit user approval before writing code.
